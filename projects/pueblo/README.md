# Pueblo al atardecer

Proyecto de referencia planeado. Construir una calle con primitivas y prefabs propios, una puerta Luau, una rampa, una caja dinámica, un farol Slang editable y un emisor de audio posicional.

Mantener escenas, prefabs, materiales, texturas, sonidos, scripts y shaders bajo Content cuando se incorporen los recursos. Preparar variantes reproducibles de 1.000 y 10.000 instancias y una ruta de cámara compartida. Verificar el estilo a 320 × 180, el comportamiento en Play y el arranque del Player exportado.
